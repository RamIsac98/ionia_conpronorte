# ionia_conpronorte

Addon Odoo 19 de la operación Conpronorte (Pozos, Gestión, Flota, Mantenimiento y Rentabilidad USD/Bs).

El módulo está en la **raíz** de este repo para que la integración Git de CloudPepper lo tome directo en el addons_path.

Instalar: Apps -> Actualizar lista de aplicaciones -> "Ionia Conpronorte".
